# Linear × GitHub Integration Playground

This repository is used to demonstrate the Linear GitHub integration,
with a focus on pull request reviews and status tracking.

## What this repo is for
- Demonstrating PR lifecycle states (Draft → Review → Approved → Merged)
- Showing how Linear tracks PR review status without switching to GitHub
- Supporting sales demos and customer walkthroughs

## Typical workflow
1. A Linear issue is created
2. A pull request is opened and linked to the issue
3. Review status updates automatically appear in Linear
4. The issue moves forward as the PR progresses

## Notes
This repository contains simple documentation-only changes to keep demos
lightweight and easy to reset.
